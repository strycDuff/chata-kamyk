# Chata Kamyk

Projektová dokumentace chaty: interaktivní návrh koupelny a SmartHome / elektroinstalace.

## Lokálně

Otevři `index.html` v prohlížeči, nebo:

```bash
npx --yes serve .
```

## Deploy (Cloudflare Pages)

```bash
npx wrangler pages deploy . --project-name=chata-kamyk
```

## Struktura

- `/` — rozcestník
- `/koupelna/` — interaktivní půdorys
- `/smarthome/` — projektová dokumentace SmartHome
